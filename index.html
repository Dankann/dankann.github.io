About

Ten years in games, currently Senior Unity Engineer at Ironbelly Studios on Godforge, a live free-to-play title. I work on both sides of the release: the Unity code players run, and the infrastructure that turns a changelist into a build in their hands.

The last two years have been a single arc. I built Godforge's build platform from scratch on AWS with Terraform — VPC and networking, an EC2 Jenkins controller, an EBS-persisted agent fleet with self-healing volume attach and detach. Then I migrated the existing Jenkins estate off Azure onto it, and moved the game's build and release pipelines from Azure to a Metaplay backend, both without interrupting releases. Then I made the cost visible, taking build-cost tracking from a one-shot script to a live panel in an internal ops dashboard I built on Node.js and AWS Lambda.

Alongside that: multi-platform Unity pipelines for Android, iOS and macOS; a ground-up rewrite of our in-editor build tool in UI Toolkit; automated Perforce merge-conflict resolution; incremental content-update detection so content changes stop triggering full rebuilds. Over 2,000 submitted changes in 18 months.

Before Godforge I shipped C++ gameplay systems on Fractured Veil, a multiplayer RPG on Steam, led an engineering team across concurrent Unity projects, and built realtime multiplayer for a VR/AR language-learning app on Mirror and AWS GameLift.
