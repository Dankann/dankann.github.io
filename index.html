About

Ten years in games, the last five of them at Ironbelly Studios. I'm a Senior Software Engineer on Godforge, a live free-to-play title. I joined it as a Unity engineer and now own its build, release and cloud infrastructure within a small DevOps team, working on both sides of the release: the code players run, and the infrastructure that turns a changelist into a build in their hands.

Most of my work is build and release engineering: Jenkins pipelines, cloud infrastructure on AWS with Terraform, backend systems, and multi-platform Unity builds that ship Android, iOS, Windows and macOS from one codebase. I also build the tooling around all of that, from in-editor build tools to an internal DevOps dashboard, for a team of roughly fifty developers and QA who use it every day.

I still write game code too. Before Godforge I shipped C++ gameplay systems on Fractured Veil, a multiplayer RPG on Steam, led an engineering team at Ironbelly across concurrent Unity projects, and built realtime multiplayer for Realvi, a VR/AR language-learning app.

The details live in the case studies below.
